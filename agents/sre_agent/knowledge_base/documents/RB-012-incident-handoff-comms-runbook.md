# Incident Handoff And Communications Runbook

Use this runbook when an incident needs an incident commander, structured
handoff, customer communications, or post-incident follow-up.

## Handoff Checklist

1. State current severity, impact, start time, affected users, and active
   mitigations.
2. Capture timeline, hypotheses, evidence, decisions, owners, and next update
   time.
3. Separate confirmed facts from suspected causes.
4. Include rollback criteria, escalation path, and customer communication status.

## Communication Guidance

- Initial update: acknowledge impact, scope, and investigation status.
- Follow-up: include mitigation progress and next update time.
- Resolved update: state recovery, monitoring, and post-incident review.
- Avoid naming root cause until evidence is confirmed.

## Evidence To Cite

- Incident timeline.
- Confirmed impact and affected region.
- Owner list and action items.
- Next communication time.
